# QQ 邮箱接入

在 QQ 邮箱设置中开启 IMAP 服务，并通过官方验证流程生成邮箱授权码。使用邮箱地址和授权码，连接 imap.qq.com:993。不要使用 QQ 登录密码。

把授权码存入权限 0600 的独立文件，通过 account add --provider qq --secret-file 添加。等状态为 running 后发新邮件测试。普通收件箱以外的文件夹不在首版监听范围。

认证失败时先检查 IMAP 是否启用、授权码是否仍然有效及邮箱地址是否正确。暂停/恢复并不会更换密码；更换凭据可重新添加账户，这会建立新基线。不要在公开 issue、日志或 PR 中贴授权码。

官方入口：https://mail.qq.com/
